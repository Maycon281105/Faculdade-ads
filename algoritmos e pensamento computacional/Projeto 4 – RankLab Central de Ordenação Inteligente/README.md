## Sobre o projeto

O RankLab é um programa desenvolvido em linguagem C
para organizar dez pontuações utilizando três algoritmos
de ordenação: Bubble Sort, Selection Sort e Insertion Sort.

O programa recebe dez valores entre 0 e 100, valida
as entradas e cria três cópias do vetor original.

Depois, cada cópia é ordenada por um algoritmo diferente.
O sistema também conta as comparações realizadas,
verifica se os resultados são iguais e apresenta a menor
pontuação, a maior pontuação e a mediana.

## Algoritmos utilizados

### Bubble Sort
Compara os elementos vizinhos e troca suas posições
quando estão fora de ordem.

### Selection Sort
Procura o menor elemento do vetor e coloca esse
elemento na posição correta.

### Insertion Sort
Organiza os elementos um por um, inserindo cada valor
na posição correta entre os elementos anteriores.
